# Definition of Ready

- [ ] Desired user or system outcome is explicit.
- [ ] Acceptance criteria are observable.
- [ ] In-scope and out-of-scope areas are named.
- [ ] Relevant instructions and existing patterns were inspected.
- [ ] Dependencies, data changes, and external effects are identified.
- [ ] Risk level and verification approach are recorded.
- [ ] Decisions requiring user authority are resolved or isolated.
