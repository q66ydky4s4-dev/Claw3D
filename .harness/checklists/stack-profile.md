# Stack profile checklist

- [ ] Claims link to repository evidence.
- [ ] Runtime and package manager versions are recorded or unknown.
- [ ] Frameworks, persistence, auth, billing, and services are identified.
- [ ] Setup, dev, test, lint, typecheck, build, and migration commands are recorded.
- [ ] Lockfiles and generated/vendor boundaries are noted.
- [ ] Environment variables are named without exposing values.
- [ ] Facts, inferences, conflicts, and unknowns are distinguished.
