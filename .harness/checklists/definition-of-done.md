# Definition of Done

- [ ] Every acceptance criterion has evidence.
- [ ] Relevant success, failure, and boundary paths were checked.
- [ ] Tests and static checks appropriate to risk pass.
- [ ] Security, privacy, accessibility, and performance were considered.
- [ ] Documentation and examples match changed behavior.
- [ ] Unrelated user changes remain intact.
- [ ] Residual risks, skipped checks, and assumptions are reported.
