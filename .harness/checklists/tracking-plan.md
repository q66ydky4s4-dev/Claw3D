# Tracking plan checklist

- [ ] Each event has trigger, purpose, owner, schema, version, and environment.
- [ ] Identity, consent, retention, redaction, and access are explicit.
- [ ] Deduplication, ordering, timestamps, retries, and offline behavior are defined.
- [ ] Development/test traffic is separable from production.
- [ ] Samples reconcile with a source of truth.
- [ ] Alerts detect missing, duplicated, or malformed events.
