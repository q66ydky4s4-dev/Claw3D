# Release checklist

- [ ] Intended scope and diff are reviewed.
- [ ] Version and changelog agree.
- [ ] Required quality gates pass with recorded evidence.
- [ ] Data and configuration migrations are rehearsed.
- [ ] Rollout, monitoring, rollback trigger, and owner are defined.
- [ ] Secrets and artifacts are handled safely.
- [ ] Human authorization exists for deploy, publish, merge, and tag actions.
