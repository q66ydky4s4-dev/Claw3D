# Performance budget

- [ ] User-visible path, workload, environment, and baseline are recorded.
- [ ] Latency percentile, throughput, memory, CPU, network, or bundle budget is explicit.
- [ ] Measurement is repeatable and includes variance.
- [ ] Correctness and cold/warm behavior are preserved.
- [ ] Regression threshold and owner are defined.
- [ ] Before/after evidence supports every optimization claim.
