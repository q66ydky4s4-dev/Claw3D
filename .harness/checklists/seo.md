# SEO checklist

- [ ] Intended public routes return correct status and index directives.
- [ ] Canonical, metadata, headings, links, sitemap, and robots behavior agree.
- [ ] Structured data matches visible content.
- [ ] Rendering and critical content work for crawlers and users.
- [ ] Performance, mobile layout, accessibility, redirects, and duplicates are checked.
- [ ] Claims and target intent are supported by useful content.
