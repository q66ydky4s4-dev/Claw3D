# MCP connection checklist

- [ ] Server/provider, owner, purpose, and environments are recorded.
- [ ] Tools/resources/prompts and mutation capability are inventoried.
- [ ] Authentication, scopes, secrets, and data classes use least privilege.
- [ ] External content is treated as untrusted data.
- [ ] Timeouts, quotas, errors, audit logs, and disable path are defined.
- [ ] Mutating calls require the intended authority and confirmation boundary.
