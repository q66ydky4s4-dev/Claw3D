# Integration change checklist

- [ ] Provider, owner, purpose, environments, and data classes are recorded.
- [ ] Credentials use least privilege and safe storage.
- [ ] Input schemas and inbound signatures are validated.
- [ ] Timeouts, retries, idempotency, quotas, and ordering are defined.
- [ ] Logs and metrics avoid secrets and sensitive payloads.
- [ ] Fixture/sandbox tests cover dependency failures.
- [ ] Disable switch, reconciliation, and recovery paths exist.
