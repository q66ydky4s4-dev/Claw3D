# Data change checklist

- [ ] Invariants, ownership, lifecycle, and sensitive fields are explicit.
- [ ] Forward and backward compatibility are defined.
- [ ] Constraints and indexes match real access paths.
- [ ] Locks, transactions, and backfill bounds are assessed.
- [ ] Authorization and row-level access are tested where applicable.
- [ ] Validation, rollback, and recovery are documented.
- [ ] Production execution has explicit authorization.
