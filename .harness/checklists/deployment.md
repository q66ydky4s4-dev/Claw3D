# Deployment checklist

- [ ] Commit, version, artifact digest, environment, and owner are explicit.
- [ ] CI, migrations, smoke tests, monitoring, and rollback were verified.
- [ ] Configuration and secrets are present without disclosure.
- [ ] Rollout stages, health thresholds, timeout, and stop trigger are defined.
- [ ] Compatibility and data rollback constraints are known.
- [ ] Production execution has explicit authorization.
