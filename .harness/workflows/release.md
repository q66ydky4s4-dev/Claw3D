# Release workflow

## Inputs
Approved change, test evidence, version decision, rollout environment.

## Steps
1. Release confirms scope, version, changelog, artifacts, and approvals.
2. QA confirms required gates; Security confirms unresolved risk disposition.
3. Release writes rollout, monitoring, and rollback instructions.
4. A human authorizes any merge, tag, publish, or deploy action.
5. Release records outcome and follow-up.

## Gate
Release checklist is complete and authorization is explicit.

## Outputs
Release packet, rollback plan, evidence, and outcome record.
