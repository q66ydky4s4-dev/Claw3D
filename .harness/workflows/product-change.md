# Product change workflow

1. Planner completes intake; Stack Analyst refreshes relevant profile sections.
2. UX maps the journey and states when user behavior changes.
3. Frontend, Backend, and API define one joined boundary contract.
4. Database, Auth, Billing, or Integrations join only for touched surfaces.
5. Implementer delivers vertically, then core Review and QA gates run.

## Gate
Interface states and service contracts agree, and Definition of Done passes.
