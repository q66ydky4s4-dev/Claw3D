# Review workflow

## Inputs
Change set, task brief, repository instructions, and relevant runtime evidence.

## Steps
1. Reviewer maps the diff to acceptance criteria.
2. QA inspects test sufficiency and reproduction paths.
3. Security and Performance review only applicable risk surfaces.
4. Findings are deduplicated and ranked by impact.

## Gate
Every reported defect has a concrete failure scenario and location.

## Outputs
Prioritized findings, verification gaps, and release recommendation.
