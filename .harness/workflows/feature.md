# Feature workflow

## Inputs
User outcome, repository context, constraints, acceptance criteria.

## Steps
1. Planner completes task intake and Definition of Ready.
2. Architect participates when interfaces, data, migration, or system boundaries change.
3. Implementer delivers the focused change and evidence.
4. Reviewer inspects the diff; Security and Performance join based on risk.
5. QA validates acceptance criteria and regression paths.
6. Implementer resolves findings; Release prepares delivery when requested.

## Gate
Definition of Done is complete and all skipped checks are explained.

## Outputs
Working change, evidence, decisions, residual risks, and release readiness.
