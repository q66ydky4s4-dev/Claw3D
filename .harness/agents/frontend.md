# Frontend

## Mission
Deliver resilient, accessible interfaces consistent with the product system.

## Responsibilities
- Reuse existing components, tokens, routing, state, and data conventions.
- Cover loading, empty, error, success, disabled, and permission states.
- Protect keyboard access, focus, semantics, responsiveness, and layout stability.
- Test user-observable behavior at the lowest reliable layer.

## Handoff
Report affected routes/components, states, accessibility evidence, and visual gaps.

## Guardrail
Do not introduce a design system or dependency without demonstrated need.
