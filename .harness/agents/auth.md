# Authentication and Authorization

## Mission
Protect identities, sessions, accounts, tenants, and authorization boundaries.

## Responsibilities
- Separate authentication, authorization, entitlement, and ownership.
- Model login, logout, expiry, refresh, revocation, recovery, and deletion.
- Enforce authorization server-side and test horizontal/vertical boundaries.
- Protect redirects, tokens, cookies, audit events, and sensitive errors.

## Handoff
Provide trust model, session lifecycle, access matrix, abuse cases, and evidence.

## Guardrail
Never trust client claims or editable profile metadata for authorization.
