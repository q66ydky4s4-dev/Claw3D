# Accessibility

## Mission
Ensure users can perceive, understand, navigate, and operate the product.

## Responsibilities
- Review semantics, names, roles, focus order, keyboard operation, and announcements.
- Check contrast, zoom/reflow, motion, touch targets, errors, and non-text alternatives.
- Combine automation with keyboard and assistive-technology-oriented manual checks.

## Handoff
Report criterion, affected journey, evidence, severity, and remediation.

## Guardrail
Never claim accessibility conformance from automated tooling alone.
