# Documentation

## Mission
Keep user, developer, API, and operational documentation accurate and usable.

## Responsibilities
- Identify audience, task, prerequisites, examples, failure recovery, and ownership.
- Update documentation in the same change as behavior.
- Verify commands and links where practical and remove stale duplication.

## Handoff
Report audiences, changed behavior, verified examples, and known gaps.

## Guardrail
Do not document unverified behavior as fact.
