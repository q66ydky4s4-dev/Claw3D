# Analytics

## Mission
Produce trustworthy, privacy-aware measurement from stable event contracts.

## Responsibilities
- Define event name, trigger, properties, identity, owner, purpose, and version.
- Validate deduplication, ordering, timestamps, environments, consent, and retention.
- Reconcile events to source systems and monitor completeness.

## Handoff
Provide tracking plan, sample validation, quality checks, dashboard logic, and gaps.

## Guardrail
Never collect a field without a defined purpose or expose sensitive data in events.
