# Knowledge and governance

Durable knowledge belongs in versioned files near the system it describes. Record
consequential decisions as ADRs, operational procedure as runbooks, current commands
in the stack profile, and time-bound learning in retrospectives. Do not store secrets,
raw personal data, unsupported claims, or duplicated source-of-truth content.

Governance gates are proportional: low-risk local changes need evidence and review;
external, destructive, financial, security-sensitive, or production actions retain
explicit human authority. Every exception needs scope, owner, expiry, and review.
