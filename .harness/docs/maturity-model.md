# Harness maturity model

| Level | Meaning | Evidence |
|---|---|---|
| 0 Ad hoc | Outcome and checks vary | None |
| 1 Defined | Instructions, workflow, owners | Versioned files |
| 2 Verified | Installation and checks repeat | Validator evidence |
| 3 Measured | Scenarios detect outcome regression | Eval reports |
| 4 Adaptive | Evidence drives reviewed changes | ADRs and trends |

Version 1.0.0 certifies Level 2. Level 3 requires representative outcome runs on
chosen hosts and models with stored scored reports.
